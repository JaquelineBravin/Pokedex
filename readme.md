# Pokedex

Projeto de uma Pokédex simples desenvolvida com JavaScript puro, HTML e CSS, consumindo a API pública do PokeAPI.

## Descrição

Este projeto exibe uma lista de Pokémon com:

- nome
- número
- tipo(s)
- imagem
- paginação para carregar mais itens

A aplicação consome a API da PokeAPI para buscar os dados dos Pokémon e renderiza os cards dinamicamente na página.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- PokeAPI

## Como executar

Você pode abrir diretamente o arquivo `index.html` no navegador ou usar a extensão live server no Vs Code

## Funcionalidades

- listagem inicial de Pokémon
- carregamento incremental com botão "More..."
- exibição de tipos pela classe CSS
- integração com a API pública do PokeAPI

## API utilizada

A aplicação usa a API oficial:

```text
https://pokeapi.co/api/v2/pokemon
```

## Observações

- É um projeto de estudo/portfolio com foco em manipulação de DOM e requisições fetch.
